# AV Journal

A personal journal for Android. Each entry is a photo, video, or audio recording, with optional text. Entries are saved into a folder you choose, sorted into year / month / day / hour folders. The Journal tab shows your entries newest first, with thumbnails, and opens each one to view, play, or read.

## Install

On an Android phone, open this link in Chrome and install the file it downloads:
https://github.com/wurp/Audio-visual-journal/releases/download/test-build/app.apk
